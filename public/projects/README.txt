PROJECT IMAGES

Put your project screenshots/photos in this folder.
Example:
  gps-1.jpg
  gps-2.jpg

Then open:
  components/Portfolio.tsx

Find a project object and change:
  images: []

to:
  images: ["/projects/gps-1.jpg", "/projects/gps-2.jpg"]

The images will appear when the visitor clicks "View details" on that project.
